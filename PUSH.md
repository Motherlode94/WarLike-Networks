# Web Push — storage foundation
Authenticated routes: GET push-config, POST push-subscribe {app,subscription}, GET push-subscriptions, POST push-unsubscribe {id}. Maximum ten subscriptions per account; endpoint ownership cannot transfer across accounts. Listing omits endpoint and cryptographic keys. Only explicitly allowed HTTPS provider hosts are accepted; delivery must disallow redirects and enforce expiry. No notifications are sent in this release. Before enabling delivery, implement session/device revocation on logout and global logout, opt-in UI, VAPID secrets, payload encryption and delivery tests. Apply migration 0012 before deploying.
