# Telecom delivery
After successful call or message insertion, the gateway schedules best-effort delivery using waitUntil. Recipient is resolved from the committed event, not supplied by the client. Only generic call/message payloads are sent. Missing private RPC binding, verifier failure or disabled delivery fail closed. Deploy Server's named PushSessionVerifier first; bind PUSH_SESSION_VERIFIER to that entrypoint on Networks, configure VAPID secrets and apply migrations 0012/0013 before setting PUSH_DELIVERY_ENABLED=true. Keep flag off until runtime certification. No durable retries yet. Chat delivery is separate. The runtime pack includes both crypto and router modules.
