# Runtime release gate
CI replays all migrations in an isolated SQLite database and builds an immutable runtime artifact with expected schema. This does not mutate Cloudflare. Before production upload, compare the live D1 schema against schema.json, record a Time Travel bookmark, apply only missing migrations in order, and preserve Worker settings and secret bindings. Deploy worker.mjs and numbers.js as modules; verify the active version and service bindings. Never replay ALTER TABLE migrations blindly. Production automation requires an explicitly scoped deployment credential and approval gate.
